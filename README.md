# Syntra

**Multiple models. One intelligence.**

Syntra is a Windows desktop application designed to bring multiple AI language models into one unified interface. Built with C# and WPF, Syntra focuses on making local AI more accessible through a streamlined application experience and an orchestration layer for working with models.

Powered by Ollama for local model integration, Syntra aims to make experimenting with different models, managing conversations, and coordinating AI responses easier from a single workspace.

## What is Syntra?

Syntra is an ongoing software project exploring a more flexible way to work with AI models. Instead of treating each model as a separate tool, Syntra provides a foundation for connecting models through a common application and orchestration architecture.

## Project goals

- **Unified interface:** Work with AI models from one desktop application.
- **Local AI integration:** Connect to locally running models through Ollama.
- **Model flexibility:** Make it easier to select and experiment with supported models.
- **AI orchestration:** Build a foundation for coordinating model responses through configurable workflows.
- **Continuous improvement:** Develop through testing, bug reports, and community feedback.

## Current status

Syntra is under active development. Version 0.2 is being prepared for beta testing, and features, compatibility, and reliability are still being evaluated.

## Technology

- C#
- WPF
